Included
--------
- Arabic RTL storefront inspired by the attached EFRIN ONE reference
- Public storefront, search, category filters, product details, reviews
- Cart, coupons, checkout, order confirmation and customer account
- Crypto-first checkout with USDT, USDC, BTC and ETH choices, plus network selection
- Vendor dashboard with analytics, products, orders, payouts, coupons, settings
- Admin control center with vendors, products, orders, customers, payouts, coupons, analytics
- Local browser persistence via localStorage for the demo experience

This is a complete front-end marketplace build. Crypto selection is currently a demo flow:
connect a wallet gateway such as BTCPay Server, Coinbase Commerce or NOWPayments, plus a
production API, database and email service before accepting real money or customer data.
